# Student Marks Calculator

A simple Python project that calculates a student's total marks, average, percentage, grade, and pass/fail result.

## Features

- Takes student's name
- Takes marks for 5 subjects
- Calculates total marks
- Calculates average
- Calculates percentage
- Assigns a grade
- Shows Pass/Fail result

## Technologies Used

- Python
- Python IDLE

## How to Run

1. Download `project1.py`
2. Open it using Python IDLE
3. Run the program
4. Enter the student's name and marks when asked
